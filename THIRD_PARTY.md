# Marcas e componentes de terceiros

O PlanMeter é um projeto independente. Não é afiliado, patrocinado ou endossado por OpenAI, Anthropic ou Z.ai.

| Identificação | Titular |
| --- | --- |
| Codex e OpenAI | OpenAI |
| Claude e Claude Code | Anthropic |
| Z.ai | Respectivo titular da marca Z.ai |

Os favicons dos provedores não são redistribuídos neste repositório. O build pode obtê-los diretamente dos sites oficiais, conforme `scripts/provider-icons.json`, para uso local. A opção `PLANMETER_ICON_MODE=initials` usa ícones próprios gerados pelo projeto. Nomes, logos e marcas permanecem sujeitos aos direitos e termos de seus titulares. Sua inclusão não transfere direitos sobre a marca nem os disponibiliza sob a licença MIT do código próprio.

O Codex CLI e o Claude Code são produtos separados, instalados e autenticados pelo usuário. A licença deste repositório não abrange esses produtos nem concede acesso aos serviços dos provedores.

Antes de redistribuir uma versão modificada, revise também a origem e os termos aplicáveis a cada recurso de terceiros incluído nessa versão.
