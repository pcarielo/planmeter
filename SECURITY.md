# Relatar uma vulnerabilidade

Não publique segredos, credenciais ou detalhes que permitam explorar uma vulnerabilidade ainda não corrigida em uma issue pública.

Use a opção privada **Report a vulnerability** na área Security do repositório, quando disponível. Se a opção não estiver disponível, abra uma issue apenas solicitando um canal privado de contato, sem detalhes de exploração ou dados sensíveis. Este projeto não promete prazo de resposta ou correção.

Em um relato privado, inclua a versão ou commit, o comportamento observado, as condições necessárias e uma reprodução com dados sintéticos. Remova tokens, chaves, nomes de conta, caches reais e logs com dados pessoais.

A implementação e os limites de armazenamento estão descritos em [docs/security.md](docs/security.md). Builds locais usam assinatura ad hoc; o projeto ainda não oferece assinatura Developer ID ou notarização.
